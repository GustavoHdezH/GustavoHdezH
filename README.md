<h2>Featured Projects</h2>

### <a href="https://github.com/GustavoHdezH/Hydra-Rapute">🔥 Hydra-Rapute</a>

A high-performance command-line tool for parallel archive decompression. Hydra processes multiple compressed files simultaneously across various formats (ZIP, TAR.GZ, TAR, TAR.XZ, 7z) from a specified input directory and extracts their contents to an organized output structure, creating subfolders named after the original files.

**Key Features:**
- Parallel decompression for improved performance
- Support for multiple archive formats
- Automatic organization of extracted files
- Efficient batch processing

**Tech Stack:** Python • Rust • CLI Tools • Archive Processing

---

### <a href="https://github.com/GustavoHdezH/Decryptor">🔐 Decryptor</a>

A secure and efficient command-line decryption tool that simplifies the process of decrypting files. Decryptor handles popular encryption formats (GPG and Age) with support for asymmetric cryptography using public/private key pairs.

**Key Features:**
- Support for GPG and Age encryption formats
- Asymmetric cryptography (public/private key pairs)
- Fast and efficient decryption operations
- User-friendly command-line interface
- Secure handling of encrypted data

**How It Works:**
- **Public Key:** Can be shared with anyone; used to encrypt files for the key owner
- **Private Key:** Kept secret; used to decrypt files encrypted with the corresponding public key

**Tech Stack:** Rust • Cryptography • CLI Tools • Security
